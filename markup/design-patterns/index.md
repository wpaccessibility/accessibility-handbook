# Design Patterns

There are a number of common design patterns used inside WordPress or in many third party applications that the Accessibility Team has had reason to comment on at various times. For each pattern, we have specific recommendations for what to avoid and how to implement best practices for that pattern.

- [Post Excerpts](https://make.wordpress.org/accessibility/handbook/markup/post-excerpts-for-an-archive-template/)
- [Dialog Modals](https://make.wordpress.org/accessibility/handbook/markup/dialog-modal/)
- [Infinite Scroll](https://make.wordpress.org/accessibility/handbook/markup/infinite-scroll/)
